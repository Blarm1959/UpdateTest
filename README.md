# UpdateTest

Regression test project for **Blarm Generic Project Updater**.

UpdateTest is intentionally small and exists solely to verify that
`ProjectUpdate.ps1` continues to function correctly after changes.

Nothing in this project exists unless it tests some aspect of the updater.
